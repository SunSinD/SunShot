# Release scope

SunShot starts from ShareX 21.0.0 and keeps its capture menus, task workflows, history views and settings model.

The release work covers:

- ShareX issue #9044: SunShot checks its own releases and automatic checks start off.
- Issues #8986 and #8952: the 21.0 main window stays in place with a smaller toolbar and focused menus.
- Issue #8911: new profiles use local capture tasks and selected-file uploads ask for confirmation.
- Issue #8909: watched files can finish growing or unlock after more than five seconds.
- Issue #9031: a right-click editor selection notification bug is fixed.

See the linked issue reports for the original context. Broader beta testing is still needed for inherited features, providers, hardware encoders and unusual display setups.
