# Changes

## 0.1.2 (2026-11-09)

- Windows 10 version 2004 and newer are supported.
- ShareX import reports FFmpeg and recording-device limits.
- Windows 11 window-corner settings are guarded on older Windows versions.

## 0.1.1 (2026-11-08)

- ShareX 22.0 through 22.4 settings and capture history can be imported.
- Import reports unsupported settings and creates a backup before restart.
- Watch-folder, startup, uploader and editor fixes improve the release build.

## 0.1.0

- First SunShot release based on ShareX 21.0.0.
- Added SunShot branding, a compact toolbar, local defaults and ShareX settings import.
- Moved to .NET 10 and updated SSH.NET and SQLite dependencies.
